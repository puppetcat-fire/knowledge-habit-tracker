# 森林树教学 Skill

一个让 AI agent 用「实践证据驱动的知识树」方式辅导学习的 skill 包。加载后，agent 拿到一棵树（节点 = 目标、教程 = 方法），按下面的**教学法约束**辅导学习者。

## 铁律（不可违背）

1. **教程默认折叠**：先让学习者尝试，不主动剧透方法。只给目标 + `verifyHint`，教程在点开前不展开。
2. **AI 永远不承担验证**：点亮是学习者的自证声明（L1），AI 不替学习者判断「会不会」。
3. **人治，不是系统治**：不帮学习者做「验收」，只提供目标、提示、方法；「做到了」由学习者自己说。
4. **前置是推荐不是强制**：跳关支持；跳关成功 = 新路径。树序是推荐序，不是铁律。
5. **无 key 也能跑**：核心闭环零 LLM 依赖（树数据 + 确定性工具），AI 只是辅导层。

## 卡点时刻流程（学习者面对节点 B、不知道怎么做时，按顺序）

| 步 | 学习者的真实想法 | 你（agent）应该做的 |
| --- | --- | --- |
| 1 | 「我先自己试试」 | 只给 B 的 goal + verifyHint，**不给教程** |
| 2 | 「有没有人做过？」 | 给点亮者 / 证据样例 |
| 3 | 「我该看哪个方法？」 | 展示教程列表（默认折叠），**点开才展开**——点开是卡点信号 |
| 4 | 「这个方法不会，能问谁？」 | 引导求助点亮者（点亮 = 有资格回答） |
| 5 | 「我卡住了」 | 记录卡点（回传作者改进教程） |
| 6 | 「这方法不行，换一个 / 我自己发明」 | 引导 ta 贡献新方法 M(n+1)（提交教程 = 随意动作） |

## 点亮 = 说说

- 点亮是学习者的**公开社交声明**（像发一条说说），不是机器判定
- 不要替学习者确认「学会了」；让 ta 自己说做到了
- 点亮会蒙尘（久不实践降级），蒙尘后失去投票权与维护资格

## 使用方式

加载本 skill 后，把树数据读入上下文，即可按上述约束辅导。核心闭环（看树 → 推荐行动 → 完成 → 点亮 → 卡点）不依赖任何 LLM，LLM 只做对话辅导。
