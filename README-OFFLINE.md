# 知识习惯跟踪器 - 完全离线版

一个完全在浏览器中运行的习惯跟踪工具，无需服务器，无需网络连接。

## 🎯 特性

- **完全离线**：所有数据存储在浏览器本地
- **无需安装**：只需一个HTML文件
- **跨平台**：在任何现代浏览器中运行
- **数据安全**：数据永不离开您的设备
- **数据导出**：支持完整数据备份和恢复
- **开源免费**：MIT许可证

## 📦 文件结构

```
knowledge-habit-tracker-offline/
├── index-offline.html      # 主HTML文件
├── app-offline.js         # 离线JavaScript代码
├── style.css              # 样式文件
└── README-OFFLINE.md      # 本说明文件
```

## 🚀 快速开始

### 方法1：直接使用
1. 下载所有文件到本地
2. 用浏览器打开 `index-offline.html`
3. 开始使用！

### 方法2：在线分发
1. 将文件上传到任何静态文件托管服务（GitHub Pages、Netlify、Vercel等）
2. 分享链接给其他人
3. 每个人都可以在浏览器中使用，数据存储在他们自己的设备上

## 🔧 功能说明

### 1. 习惯管理
- 创建新习惯（60-255天周期）
- 跟踪习惯进度
- 查看历史习惯
- 从习惯开始计时

### 2. 时间跟踪
- 专注计时器
- 行动预测
- 计时日志
- 完成报告生成

### 3. 完成记录
- 记录每日完成事项
- 按时间筛选查看
- 关联习惯标签

### 4. Bug收集（本地）
- 报告使用中的问题
- 数据存储在浏览器本地
- 支持严重级别分类

### 5. 数据管理
- **导出所有数据**：生成JSON备份文件
- **导入数据**：从备份文件恢复
- **清除数据**：重置所有本地存储
- **存储统计**：查看数据使用情况

## 💾 数据存储

### 存储位置
- **浏览器LocalStorage**：所有数据存储在浏览器中
- **完全私有**：数据永不离开您的设备
- **跨会话持久**：关闭浏览器后数据仍然存在

### 数据安全
- 无服务器，无数据传输
- 无用户跟踪，无数据分析
- 数据完全由用户控制

### 备份策略
1. 定期使用"导出所有数据"功能备份
2. 备份文件是标准JSON格式
3. 可以在任何设备上导入恢复

## 🌐 离线使用说明

### 优势
- ✅ 无需网络连接
- ✅ 无需服务器费用
- ✅ 数据完全私有
- ✅ 响应速度快
- ✅ 可在任何环境中使用

### 限制
- ⚠️ 数据仅存储在单个浏览器中
- ⚠️ 清除浏览器数据会丢失所有记录
- ⚠️ 不同设备间需要手动同步（通过导出/导入）

## 🔄 数据迁移

### 从原版迁移
1. 在原版中导出数据
2. 在离线版中导入数据
3. 所有习惯和记录都会迁移

### 跨设备同步
1. 在设备A上导出数据
2. 将备份文件传输到设备B
3. 在设备B上导入数据
