# 点亮界面方向

## 产品任务

习惯记录端让人以很少的注意力找到下一步，并留下实际事件与计时。
知识平台展示知识关联、方法和真实实践；个人主页串起一个人的贡献。
两个系统保持独立服务，共用账号。此轮只调整呈现与导航，不改自证、可见性、习惯里程碑、推荐与节点归属规则。

## 视觉基准

| 用途 | 色值 |
| --- | --- |
| 习惯工作台背景 | `#f3f6fa` |
| 阅读面板 | `#ffffff` |
| 主文字 | `#213149` |
| 行动入口 | `#345ec9` |
| 知识地图背景 | `#101e32` |
| 自证点亮 | `#ebd6a9` |

中文使用系统无衬线字体，优先 PingFang SC / Microsoft YaHei；拉丁字符使用 Segoe UI。
标题 26–38px、栏目标题 18–20px、内容 14–16px、辅助说明 12–13px。
数字使用等宽数字，不为了装饰添加英文大写标签。

## 布局与取舍

桌面习惯端使用左侧导航与右侧工作区，手机端导航在内容之前。

```text
导航       账号身份
           下一步行动         习惯 / 个人主页 / 知识平台
           今日概览与当前状态
           最近的真实记录
```

下一步占主要视觉权重。其他去向是列表而非同等大小的卡片；统计采用同一容器中的分区。
计时页面将动作选择、计时控制、两类日志分开，保持操作顺序。

知识平台保持二维关系图；先修与实例边不合并。图谱采用深蓝阅读空间，实际自证使用金色。
节点详情承担长文本、方法和记录阅读，教程仍默认折叠。手机打开节点后定位到详情，回到树后将焦点还给图谱。
创建、备份和退出收进管理菜单，减少常驻导航的干扰。
个人主页以实践时间线、方法与归属为主体，统计和个人资料为辅助。

## 质量检查

使用 frontend-design 确立方向，按 web-design-guidelines 检查键盘焦点、语义控件、跳过导航、窄屏溢出、减少动态效果和空状态。
截图使用已有验证账号和真实记录，不填造展示数据。原行为测试用于检查界面调整没有破坏两端原有流程。
