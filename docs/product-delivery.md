# 两个系统：运行与验收

本轮以原目录最新提交和已有未提交修改为基线推进，保留习惯系统、二维知识树、关系类型、教程默认折叠和点亮自证等原设计。

## 打开结果

在本目录运行 `npm run start:community` 可验收单域名导航。默认入口为 <http://127.0.0.1:3105/>，同一地址下的 `/habit/` 打开习惯记录，`/platform/` 打开知识平台，`/review/` 打开独立的社区验收界面。各入口共用登录账号，习惯记录与社区的行动档案分别保存。测试实例默认使用独立的 `data/community-local`，也可以用 `DATA_DIR` 指定目录。

双击 `start-product.cmd` 可启动本地站点。它默认在端口 3000 提供首页、习惯系统和知识平台。`/knowledge/` 兼容已有知识链接。启动器会等待服务就绪并复用已运行的服务。首次运行需安装 Node.js，并在项目目录执行 `npm install` 安装依赖。

后台运行的日志和进程标识保存在数据目录的 `service-out.log`、`service-error.log` 与 `service-process.json`。Windows 注销或重启后需重新运行启动器；当前没有安装系统常驻服务。

生产站点仍按同域子页面部署。上线前需要让生产反向代理把新增 API 转发给主站，并用现有数据的脱敏副本验证恢复和权限。见[部署说明](../deploy/README.md)。

站点的「我的想要」与教程材料清单使用各自已有的数据。账号备份覆盖教程材料清单。站点需求和公开图谱仍由主站数据目录备份。独立社区验收的行动档案也沿用单独的数据格式。

## 可亲自验证的完整流程

知识平台顶栏新增“个人主页”：个人介绍、正在探索的事、实践时间线、所贡献的方法、节点持有和本人实际计时时间。个人资料默认私人，公开介绍不会连带公开私人事件与方法；别人的主页只展示可访问的公开贡献。实践作者名字可以进入对应主页，主页有 `#person/<账户ID>` 地址，刷新仍可打开。个人资料纳入完整备份，恢复后重新作为私人资料保存。

图谱采用知识地图的全览/放大层次：全览以可读名称与曲线路径显示知识结构，放大保留完整节点卡片；点亮与已有实践用不同亮度呈现。原有前置/后置、实例/原理、教程默认折叠、5–15 分钟目标与自主跳关规则继续保留，界面数量由当前可见的真实记录产生。

1. 打开知识平台，注册自己的本机账户。建立一棵关于你想做的事的知识树，默认私人；数学种子树仍保留。
2. 在节点贡献方法，写具体步骤、前五分钟起步与可选资料。默认私人，需要共享时主动勾选。保存后默认折叠。
3. 展开并选择“用这个方法去做”。习惯页承接动作、目标和方法；开始、暂停、重载、结束后仍保留本次来源。
4. 在习惯记录中查看实测时间、事件、当时目标与所用知识；在平台对应节点看到实践草稿。自证点亮是独立动作，计时结束不会代替完成确认。
5. 在公开节点分享自证实践，用另一个账户可查看。私人记录、私人方法和私人树不可由其他账户读取；撤回分享后保留自己的原记录。
6. 修改自己的方法，再查看过去实践的方法快照/版本。旧记录仍指向原内容。不同窗口编辑同一版本时，陈旧修改会被拒绝并保留输入。
7. 在任一系统打开“完整备份”，导出并保存。选择文件先看到数量与后果，再确认恢复。恢复的内容默认私人，不会自动重新发布，也不覆盖其他账户。

图片每次最多 4 张、每张不超过 2MB，支持 PNG/JPEG/WebP/GIF。登录账户记录的图片由服务端鉴权；离线模式将图片保存到浏览器空间，容量不足会报告失败。

## 保存与运行边界

登录后，账户资料位于本次服务的 `data/` 目录，浏览器保留同步缓存。服务断开时保留未保存内容，并提供重试和导出。离线使用的数据只在当前浏览器，不会因为登录而自动公开。

服务端采用原子文件替换；完整恢复使用事务日志，启动或下一次请求会重放未完成事务。损坏的账户/节点/记录文件停止读取或写入，不把损坏误当空账户。建议定期同时保存完整账户备份与整个数据目录。完整账户备份不包含密码、会话和运营账本。

目前适用于单 Node 进程、本机或明确配置的小范围自托管。不要让多个进程同时写同一数据目录。互联网开放仍需 HTTPS、明确的服务地址、运维备份、审核/反滥用和部署验证；当前没有执行公网发布，也没有宣称支持大规模并发。

可配置项包括 `HOST`、`PORT`、`PLATFORM_PORT`、`DATA_DIR`、`HABIT_URL`、`PLATFORM_URL`、`SECURE_COOKIES`、`TRUST_PROXY` 与 `ALLOWED_ORIGINS`。反向代理环境需设置真实链接与 HTTPS cookie；`TRUST_PROXY` 只应指向实际受信任代理。

## 收费设计的实际实现范围

免费使用不受养成里程碑影响。同一习惯连续四个本地周、每周至少五次完成后出现自愿推荐产品/理念和赞赏 2–5 元说明，没有收费锁。

产品外链可透明标记关联收益。佣金账本在运营端使用：

```powershell
node scripts/commission-ledger.js verify
node scripts/commission-ledger.js order receipt.json
node scripts/commission-ledger.js refund refund.json
```

订单格式示例：

```json
{"provider":"example","orderId":"order-001","amountFen":100000,"rateBps":50,"ownership":"group","treeId":"k9-math","nodeId":"linear-equation","holderIds":["actual-holder-id"]}
```

上述是操作格式，没有内置真实订单。录入前需取得真实渠道回执和对应节点的持有者快照。默认示例费率 0.5%，抽成一半进入持有者池、一半进入平台池；小于一分钱的金额保留精确分数。退款引用原订单，限制累计退款额，重复回执幂等。账本为 `reserved` 状态，不代表可提现余额。哈希链可检测内容被改动，不能防止拥有文件写权限的人重写整个账本。

公共池内分配权重、实际渠道、归因规则和真实支付尚未确定，不擅自采用均分或付费解锁。转群体持有、治理投票、分裂合并、跨实例交换、Android/桌面后续工作均保留在 [完整方向](product-direction.md)。

## 验证

执行 `node scripts/check.js`，依次运行 ESLint、TypeScript 与行为测试，任何一步失败立即返回非零状态。已通过的测试覆盖账户隔离、旧数据迁移、节点关系、方法历史、计时来源、保存冲突、完整恢复中断、图片权限、里程碑及佣金/退款。

浏览器实测已跑通自建树、私人方法、跨系统交接、实际计时、事件回流与私人自证。检查数据位于预览目录，与正常 `data/` 账户隔离。
